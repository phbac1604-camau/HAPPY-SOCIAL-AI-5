# HAPPY SOCIAL AI 5.0

Nhà máy sản xuất nội dung số quản lý 5 kênh Facebook.

**Trạng thái:** Kho mã nguồn dự án; chưa phải máy chủ chạy 24/7. Không lưu API Key hay token trong GitHub.

Ứng dụng Python sử dụng SQLite, Gemini, FFmpeg và Meta Graph API. Cần cấu hình dịch vụ và cấp quyền Meta trước khi xuất bản thật.
